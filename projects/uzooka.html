Uzooka — Shopify Storefront Enhancements

Uzooka is a U.S. company selling motor-vehicle components online, with more than 5,000 products. I contributed to part of the project, focused on search, catalog filtering and product-page logic.

Year
Jan 2019
Context
Uzooka · U.S. e-commerce
Role
Developer (contributor)
Live site
uzooka.com ↗

Spell-checked search

I integrated the Microsoft Bing Spell Check API to check values as they're typed into the header search field. When the API returns a correction, the suggested spelling appears at the top of the results.

A shorter, smarter catalog filter

With hundreds of car models, the filter had grown far too long. The solution: once a shopper selects a car brand, only that brand's models appear in the filter.

Headlight placement graphics

Product pages needed to show a headlight or tail-light placement graphic based on the car model and stock quantity. We used Shopify's Liquid templating language to read the current product's metadata, evaluate the values and display the correct image.

Built with

  • Shopify Liquid
  • MS Bing Spell Check API
  • JavaScript
  • jQuery
  • PHP & MySQL
