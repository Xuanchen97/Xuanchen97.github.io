D3.js World Impact Map

An interactive map, built for a public mall display, that lets people explore how World Vision Canada's work changes communities around the world — from global totals down to individual communities.

Year
Nov 2019
Context
World Vision Canada
Role
Main developer
Stack
D3.js · JavaScript · jQuery

The challenge

Donors expect greater transparency on how World Vision Canada uses the funds they entrust to it. The digital team collects impact data every year from communities around the world, and wanted to present it far more visually — as an interactive map running on a mall display.

My role

I was responsible for the main development work, and helped coordinate communication between the project manager, stakeholders and the digital team.

Walkthrough

The map works at three zoom levels, each revealing more detail about where the funds go and what they achieve.

Built with

  • D3.js API
  • JavaScript
  • jQuery
  • HTML / CSS
